# Forma Store – Product Listing
A sample product catalogue with category filtering, maximum-price filtering and sorting by price or rating.

## Run
Open `index.html` in a modern browser. No server or installation is required.

## Test
- Select each category and verify the product cards update.
- Set a maximum price and verify higher-priced products disappear.
- Sort by low-to-high price, high-to-low price and rating.
- Combine filters and sorting.
- Choose a filter combination with no matching products to test the empty state.

## Note
Products, prices and ratings are sample data for this internship exercise, not real offers or purchase listings.
